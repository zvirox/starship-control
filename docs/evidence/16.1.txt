NOTES
- `oom` is a simulated OOM kill (bounded allocation + exit 137), not a real
  host-wide memory exhaustion, so chaos suites can run safely on a dev machine.
- Fatal faults are injected through `FaultRuntime`; `RecordingFaults` lets unit
  tests exercise them without terminating the test process.
