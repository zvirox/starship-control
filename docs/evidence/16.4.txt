   unsafe-eval; renderer sanitizer strips <script> and blocks javascript: and
   data:text/html; output stays an escaped React text node.
6. Secret scrubbing + audit chain — canary removed from audit payload output;
   3-entry hash chain verifies; payload mutation changes the chain hash.

MUTATION PROOF
The renderer test disables the `javascript:` check in a temporary copy of
sanitize.js (located by the CHECK:javascript-scheme marker), imports the mutant
and asserts the payload survives. The unmodified sanitizer still blocks it, so
a disabled check makes the suite fail as required.
The Rust suite includes a hash mutation assertion (same audit fields, different
payload => different hash).
