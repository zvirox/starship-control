=== TASK 17.14 — DOWNLOAD HYGIENE ===
Date: 2026-11-27

ROOT CAUSE
`download_hf_file` relied only on an optional SHA-256; any bytes (including an
HTML error page) could be renamed into the models directory and registered as a
`ready` GGUF model. There was no delete command, and rows with missing files
still appeared selectable.

CHANGES
- crates/starship-infer/src/hf/downloader.rs: `verify_gguf_file` checks the GGUF
  magic bytes and expected size before the `.part` file is promoted; invalid
  downloads fail with `infer.checksum_mismatch` and leave no final file.
  Resume via `Range` is retained and now covered by a test.
- crates/starship-db/src/models.rs: `mark_missing_local_models` marks local rows
  whose file no longer exists as `remote_only`; `delete_model` removes a row.
- app/src-tauri/src/ipc/commands.rs: `cmd_list_models` marks missing files; new
  `cmd_model_delete{modelId}` removes the row and, for local GGUF, only a file
  that canonicalizes inside the models directory (path confinement).
- API.md / ipc.ts mirrored the new command; ModelPicker disables selection of
  local models whose status is not `ready` and labels them "Not downloaded".
