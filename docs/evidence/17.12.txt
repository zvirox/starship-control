=== TASK 17.12 — CONVERSATION MEMORY ===
Date: 2026-11-27

ROOT CAUSE (R9, confirmed in 17.0)
`cmd_mission_send_prompt` built `messages: vec![Message::user(prompt_text)]`;
stored `mission_messages` were never loaded, so a model could not remember an
earlier turn.

CHANGES
- app/src-tauri/src/ipc/commands.rs: `conversation_messages(history, max, budget)`
  maps stored `MissionMessageRecord`s to `Message`s (user/assistant/tool), keeps
  newest messages first, drops system records, and trims the oldest entries at
  40 messages / 24,000 characters. Characters/4 is a conservative estimate — no
  token count is invented. `cmd_mission_send_prompt` loads `list_messages` after
  recording the user turn and sends that context instead of a lone prompt.
- API.md documents the request-context behavior for `cmd_mission_send_prompt`.
- crates/starship-infer/src/engine.rs (tests only): `ContextEchoEngine` returns
  the full context it receives, used to prove that history reaches the model.
